# Phase 0 – Project Context & Vision

## Project Name
Personal Multi-Agent Resume Analyzer (LLM + RAG)

## Project Type
Portfolio-ready AI/ML Engineering Project  
(Agentic AI + Retrieval-Augmented Generation)

## Problem Statement
Job seekers often apply to roles without clear feedback on:
- How well their resume matches a given job description
- Which skills or experiences are missing
- Why they get rejected
- What interview questions they are likely to face

Existing tools provide keyword matching or opaque scores without
explainability or actionable improvement guidance.

## Solution Overview
This project builds a **personal AI-powered, multi-agent resume analysis system**
that evaluates a resume against a job description using:
- Structured scoring rubrics
- Evidence-backed citations
- Skill gap detection
- Resume improvement recommendations
- Role-specific interview question generation


## Target Users
- Individual job seeker (AI/ML, Data, Software roles)


## Core Capabilities
- Resume vs JD scoring using LLMs
- Transparent scoring with citations
- Multi-agent orchestration
- RAG-powered evidence grounding
- Iterative resume improvement loop

## Non-Goals
- Full ATS replacement
- Candidate ranking across multiple people
- Automated job applications

## Guiding Principles
- Explainability over black-box scoring
- Agentic decomposition of complex reasoning
- Production-quality architecture
- Resume and interview improvement focus

## Success Definition
A job seeker can:
- Understand their resume fit clearly
- Identify exact improvement areas
- Iteratively improve resume versions
- Prepare targeted interview questions
